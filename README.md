# 最后一个离开实验室的人 · 多实验室版

本次版本：20261029-multilab。

四类实验室，每类六处隐患，合计二十四处。支持自由选择与切换、独立保存首次判断和巡查进度、分别重玩、放大观察、处理反馈、巡查前后对比、检查报告及 PNG 检查卡。

| --- | --- |

| 机械加工 | 卡盘遗留扳手、防护罩未到位、地面切屑、床面油污抹布、钢材占道、工具电缆破损 |

## 部署

部署包内的 index.html、app.js、labs.js、style.css、四个场景 SVG、assets 文件夹应位于网站根目录。使用相对路径，可部署到 GitHub Pages 项目路径。无需安装依赖、编译、后端、账号登录或外部 API。

将解压后的内容上传到现有 GitHub 仓库 jiayuanxin666/last-light 的 main 分支根目录，覆盖同名文件、保留 assets 目录结构。Pages 保持 Deploy from a branch / main / (root)，等待发布完成。不要仅上传 ZIP 文件。

本地查看需要 HTTP 服务，例如在解压目录运行 `python -m http.server 8000`，再访问 http://localhost:8000/ 。不要直接双击 index.html，以免浏览器阻止场景文件的 fetch 请求。

## 保存进度

使用 localStorage 的 last-light-multilab-v2。四间实验室分别记录。重玩仅清除当前实验室记录。首次从旧版升级时迁移计算机实验室前五项进度；第六项题目已改变，因此需要重新检查运行登记。清理浏览器数据或更换设备不会同步记录。

## 场景图片

新增三类场景使用内置图像生成与编辑工具制作，运行时为 WebP 压缩资源，原始分辨率 1536 × 1024。照片仅为虚构教学情境。代码负责精确的文字、热点和处置标签，不依赖图片生成文字。

生成提示词要点：普通高校化学实验室、电子电气实验室和机械实训车间；写实材料、固定广角视点、自然白色灯光，无人物、无科幻装饰、无 UI；按上表为每间分散设置六处可观察隐患。编辑提示词要求锁定相机、光线、家具和无关物品，只表现六项经授权完成处置后的状态；待检修设备保持停用待修，不能呈现为学生自行维修。化学废液桶另经针对性编辑确保桶盖闭合。
